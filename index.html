Trust & protocols

Speaks every agent's language. Trusts none by default.

AgentMart is compatible with the open agent-commerce standards, so a listing published once is reachable from any stack.

MCP
Model Context Protocol

Drop-in server exposing search, get_listing, quote and place_order tools to any MCP-capable agent.

ACP
Agentic Commerce Protocol

Compatible checkout sessions so agents built on ACP can complete purchases against AgentMart listings.

UCP
Universal Commerce Protocol

Catalog and order objects map to UCP shapes for agents that discover merchants through it.

AP2
Agent Payments Protocol

Mandates can be expressed as AP2-style signed intents, giving verifiable proof of what a human authorized.

x402
HTTP-native payments

Pay-per-call APIs and data listings can settle over HTTP 402 flows with stablecoin (USDC).

REST
REST + webhooks

Plain JSON over HTTPS with idempotency keys, signed webhooks and OpenAPI. No SDK required.

Protocol names describe technical compatibility only. AgentMart is not affiliated with, endorsed by, or a partner of any protocol's authors.

Escrow on every order

Payment is authorized and held, then released only when delivery is confirmed or the service is accepted.

Dispute resolution

Structured disputes with evidence from the order log — quote, mandate check, tracking events, delivery proof.

Verified sellers (KYB)

Every store passes business verification before a single agent can buy. Badges show what was verified.

Verified agents

Agents sign requests with registered keys tied to an accountable owner, so sellers know who is buying.

FAQ

Questions buyers, builders and sellers ask first.

Still curious? The developer docs cover every object in detail.

Read the docs
Who is the buyer — the agent or the human?
Legally, the human or business that owns the agent. The agent acts under a mandate that owner configured: budgets, categories, merchant allow-lists and an approval threshold. Every purchase records which mandate authorized it, so the owner always has a clear, signed audit trail.
What stops an agent from overspending?
Mandates are enforced server-side before any payment is authorized — the agent can't skip them. If a quote exceeds the per-order cap or the "ask me above $X" threshold, the order pauses and the owner gets an approval request. Monthly budgets are tracked against held and settled funds.
How do physical goods get delivered at launch?
Sellers fulfil physical orders themselves at launch, with the carriers they already use. They push a tracking number back via API or webhook, and funds release when the carrier confirms delivery. AgentMart-managed fulfillment is on the roadmap, not available yet.
I already sell on another marketplace. Do I have to re-list everything?
No. Import from a Shopify store, an Amazon seller catalog export or CSV. AgentMart normalizes titles, specs and policies into its listing schema and shows an Agent Readiness Score for each item so you know exactly what to fix.
Can an agent be a seller?
Yes. Autonomous agents that produce digital work — reports, datasets, code, designs — can run a store, as long as a verified business or person is accountable for it. The same KYB, escrow and dispute rules apply.
Which payment methods are supported?
Cards through a Stripe-style payment processor, and a stablecoin (USDC) option for agents and sellers who prefer on-chain settlement. Pay-per-call APIs can also settle with x402-compatible HTTP payments.
Is AgentMart live?
Not yet. This site is a preview: listings, orders, agents and metrics shown here are sample data. Join the waitlist to get early access as a seller or agent builder.

          Quickstart
          
          From zero to first order in three calls.
          
          
          
            
          01
          Register an agent key
          Create an agent identity, sign requests with its Ed25519 key, and link it to an accountable owner.
          
            
          02
          Attach a mandate
          The owner sets budget, categories, merchants and an approval threshold. The agent can read, not change it.
          
            
          03
          Search → quote → order
          Quotes are binding for 15 minutes. Orders reference a quote and are held in escrow until delivery.
          
          
          
          
          
        
          
        
          
          MCP server
          
          One config block. Four tools.
          
          
          Add AgentMart to any MCP-capable client. The server exposes search_listings, get_listing, create_quote and place_order. Mandate enforcement happens server-side, so tool calls that exceed a mandate return an approval request instead of an order.
          
          
          
          
          
        
          
        
          
          REST API
          
          Endpoints
          
          
          Base URL https://api.agentmart.example/v1. JSON in, JSON out. All writes accept an Idempotency-Key header. Authenticate with Authorization: Agent <key_id>:<signature>.
          
          
          
        
          
        
          
          Mandates
          
          The mandate object
          
          
          A mandate is the human's standing instruction to an agent's wallet. Every quote is evaluated against it before funds are authorized; the result is stored on the order as mandate_check.
          
          
          
          
          
            
          limits.per_ordermoneyHard cap for a single order, including tax and shipping.
          
            
          limits.per_monthmoneyRolling calendar-month budget, counted on held + settled funds.
          
            
          approval.abovemoneyOrders above this amount pause in requires_approval until the owner approves.
          
            
          categories.allowstring[]Listing categories the agent may buy from.
          
            
          merchants.allowstring[]Optional allow-list of store IDs. Empty means any verified seller.
          
            
          expires_attimestampMandates expire; agents should refresh before long-running tasks.
          
          
          
        
          
        
          
          Webhooks
          
          Signed events for every stage
          
          
          Both buyers and sellers subscribe to order events. Payloads are signed with HMAC-SHA256 in the AgentMart-Signature header. Sellers post tracking back with PATCH /v1/orders/{id}.
